# 🤖 YouTube AI Content Detector

## Overview

A powerful feature that analyzes YouTube videos to detect if they're AI-generated by examining metadata, descriptions, tags, and engagement patterns.

## ✨ Features

- 🔍 **Smart Detection**: Analyzes title, description, tags, and metadata
- 🎯 **Confidence Scoring**: Provides probability (0-100%) with confidence levels
- 📊 **Detailed Breakdown**: Shows analysis by category
- 🏷️ **Indicator Tracking**: Lists all AI indicators found
- 📈 **Video Statistics**: Displays views, likes, and comments
- 🎨 **Beautiful UI**: Modern glassmorphism design
- 📱 **Fully Responsive**: Works on all devices
- ⚡ **Fast Analysis**: Results in seconds

## 🚀 Quick Start

### 1. Get YouTube API Key
```
1. Visit: https://console.cloud.google.com/
2. Enable "YouTube Data API v3"
3. Create API Key
```

### 2. Configure
```env
# backend/.env
YOUTUBE_API_KEY=your_api_key_here
```

### 3. Integrate
```javascript
// backend/server.js
app.use('/api/youtube', require('./routes/youtube'));

// frontend/src/App.jsx
import YouTubeAIDetector from './pages/YouTubeAIDetector';
<Route path="/youtube-detector" element={<YouTubeAIDetector />} />
```

### 4. Use
```
Navigate to: http://localhost:5173/youtube-detector
Paste YouTube URL → Click Analyze → View Results
```

## 🎯 What It Detects

### AI Tools & Platforms
- **Video**: Synthesia, D-ID, HeyGen, Runway, Pictory
- **Voice**: ElevenLabs, Murf, Descript, Resemble
- **Images**: Midjourney, DALL-E, Stable Diffusion, Leonardo AI
- **Text**: ChatGPT, GPT-4, Claude, Gemini, Bard

### Detection Methods
1. **Text Analysis** (40% weight) - Scans descriptions for AI keywords
2. **Title Analysis** (15% weight) - Checks video titles
3. **Tags Analysis** (15% weight) - Examines video tags
4. **Metadata** (20% weight) - Analyzes engagement patterns
5. **Channel** (10% weight) - Checks channel characteristics

## 📊 Confidence Levels

| Level | Probability | Meaning |
|-------|------------|---------|
| **High** | 60%+ | Very likely AI-generated |
| **Medium** | 35-59% | Possibly AI-generated |
| **Low** | 20-34% | Uncertain, some indicators |
| **Unlikely** | <20% | Likely human-created |

## ⚠️ Limitations

### Cannot Detect
- ❌ AI content without metadata disclosure
- ❌ Deepfakes or face swaps
- ❌ AI-edited videos (without mentions)
- ❌ Subtle AI assistance
- ❌ Videos without AI keywords

### Can Detect
- ✅ Explicit AI tool mentions
- ✅ AI platform disclosures
- ✅ AI-focused channels
- ✅ Common AI patterns
- ✅ Unusual engagement metrics
