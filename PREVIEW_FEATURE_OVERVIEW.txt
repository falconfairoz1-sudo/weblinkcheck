┌─ CACHING STRATEGY ────────────────────────────────────────────────────────────┐
│                                                                               │
│  How It Works:                                                               │
│  1. First scan of URL → Fetch from web                                       │
│  2. Cache result for 24 hours                                                │
│  3. Subsequent scans → Serve from cache                                      │
│  4. After 24 hours → Cache expires, fetch again                              │
│                                                                               │
│  Benefits:                                                                   │
│  • Faster repeated scans (< 100ms)                                           │
│  • Reduced API calls                                                         │
│  • Better performance                                                        │
│  • Lower bandwidth usage                                                     │
│  • ~80% cache hit rate                                                       │
│                                                                               │
│  Cache Key Format:                                                           │
│  preview:{url}                                                               │
│                                                                               │
│  Example:                                                                    │
│  preview:https://example.com                                                 │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘
