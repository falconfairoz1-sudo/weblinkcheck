# 🤖 YouTube AI Content Detector - Setup Guide

## Overview
This feature allows you to analyze YouTube videos to detect if they're AI-generated by examining metadata, descriptions, tags, and patterns.

## Features

### 🔍 What It Detects
- **AI Generation Tools**: ChatGPT, Midjourney, DALL-E, Stable Diffusion, etc.
- **AI Video Platforms**: Synthesia, D-ID, HeyGen, Runway, Pictory
- **AI Voice Tools**: ElevenLabs, Murf, Descript, Resemble
- **AI Keywords**: Explicit mentions of AI generation in title/description
- **Metadata Patterns**: Unusual engagement ratios, upload patterns
- **Channel Patterns**: AI-focused channel indicators

### 📊 Analysis Components
1. **Title Analysis** (15% weight)
2. **Description Analysis** (40% weight) - Most important
3. **Tags Analysis** (15% weight)
4. **Channel Patterns** (10% weight)
5. **Metadata Patterns** (20% weight)

### 🎯 Confidence Levels
- **High Confidence**: 60%+ probability
- **Medium Confidence**: 35-59% probability
- **Low Confidence**: 20-34% probability
- **Unlikely AI**: <20% probability

## Setup Instructions

### 1. Get YouTube API Key

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project or select existing one
3. Enable **YouTube Data API v3**:
   - Go to "APIs & Services" > "Library"
   - Search for "YouTube Data API v3"
   - Click "Enable"
4. Create credentials:
   - Go to "APIs & Services" > "Credentials"
   - Click "Create Credentials" > "API Key"
   - Copy your API key
5. (Optional) Restrict your API key:
   - Click on the API key
   - Under "API restrictions", select "Restrict key"
   - Choose "YouTube Data API v3"
   - Save

### 2. Configure Backend

Add to `backend/.env`:
```env
YOUTUBE_API_KEY=your_youtube_api_key_here
```

### 3. Add Route to Server

Add this line to `backend/server.js` (after other routes):
```javascript
// YouTube AI Detector routes
app.use('/api/youtube', require('./routes/youtube'));
```

### 4. Add Frontend Route

Add to `frontend/src/App.jsx` (in your routes):
```jsx
import YouTubeAIDetector from './pages/YouTubeAIDetector';

// In your Routes component:
<Route path="/youtube-detector" element={<YouTubeAIDetector />} />
```

### 5. Add Navigation Link

Add to `frontend/src/components/Navbar.jsx`:
```jsx
<Link to="/youtube-detector" className="nav-link">
  YouTube AI Detector
</Link>
```

## Usage

### Basic Usage
1. Navigate to `/youtube-detector`
2. Paste a YouTube URL (e.g., `https://youtube.com/watch?v=VIDEO_ID`)
3. Click "Analyze Video"
4. View results with AI probability and detailed breakdown

### Supported URL Formats
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`
- Direct video ID: `VIDEO_ID`

### API Endpoint

**POST** `/api/youtube/analyze`

Request:

{
  "url": "https://youtube.com/watch?v=dQw4w9WgXcQ"

## How It Works

### Detection Algorithm

1. **Text Analysis**
   - Scans title, description, and tags
   - Looks for AI-related keywords and phrases
   - Identifies AI tool/platform mentions
   - Weighted scoring based on keyword importance

2. **Pattern Recognition**
   - Analyzes engagement ratios (views/likes/comments)
   - Checks video duration patterns
   - Examines channel characteristics
   - Identifies unusual metadata patterns

3. **Confidence Calculation**
   - Combines all analysis scores with weights
   - Generates overall AI probability (0-100%)
   - Assigns confidence level (low/medium/high)
   - Lists all detected indicators

### Limitations

⚠️ **Important Notes:**
- **Metadata Only**: Cannot analyze actual video content (frames, audio)
- **Keyword-Based**: Relies on explicit mentions in text
- **Not 100% Accurate**: Should be used as guidance only
- **API Dependent**: Requires YouTube API access
- **Quota Limits**: YouTube API has daily quota limits

### What It CAN Detect
✅ Videos with AI tools mentioned in description
✅ AI-generated content with proper disclosure
✅ Videos from known AI content platforms
✅ Channels focused on AI content creation
✅ Unusual engagement patterns

### What It CANNOT Detect
❌ AI content without metadata indicators
❌ Deepfakes or AI-edited videos (without disclosure)
❌ AI-generated visuals/audio (without analysis)
❌ Subtle AI assistance in production
❌ Videos that don't mention AI tools used

## API Quota Management

YouTube API has daily quotas:
- **Free tier**: 10,000 units/day
- **Each video analysis**: ~3 units
- **~3,300 analyses per day** on free tier

To monitor usage:
1. Go to Google Cloud Console
2. Navigate to "APIs & Services" > "Dashboard"
3. Click on "YouTube Data API v3"
4. View quota usage

## Troubleshooting

### "YouTube API key not configured"
- Add `YOUTUBE_API_KEY` to `backend/.env`
- Restart backend server

### "YouTube API quota exceeded"
- Wait until quota resets (midnight Pacific Time)
- Or upgrade to paid tier in Google Cloud

### "Invalid YouTube URL"
- Ensure URL format is correct
- Try using direct video ID
- Check if video is public

### "Video not found"
- Video might be private or deleted
- Check if video ID is correct
- Ensure video is publicly accessible
