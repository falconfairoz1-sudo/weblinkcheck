# LinkGuard Extension Icons

## Required Icon Sizes
- icon16.png (16x16) - Toolbar icon
- icon32.png (32x32) - Extension management page
- icon48.png (48x48) - Extension management page
- icon128.png (128x128) - Chrome Web Store

## Icon Design Guidelines

### Colors
- Primary: #3b82f6 (Blue)
- Secondary: #10b981 (Green)
- Background: #0a0a0b (Dark)

### Design Elements
- Shield symbol for protection
- Checkmark for safety
- Modern, clean design
- High contrast for visibility

## Creating Icons

You can create these icons using:
1. **Online Tools**: Canva, Figma, or similar
2. **Design Software**: Photoshop, GIMP, or Sketch
3. **Icon Generators**: Use existing shield/security icons

## Temporary Solution

For testing, you can use these emoji-based icons:
- Create simple PNG files with shield emoji 🛡️
- Use online emoji-to-PNG converters
- Ensure proper sizing for each required dimension

## Icon Content Suggestions

### Main Icon (Shield Design)
```
🛡️ LinkGuard
- Shield shape
- Blue gradient background
- White checkmark or "LG" text
- Clean, professional look
```

### States
- **Active**: Bright blue shield with checkmark
- **Warning**: Yellow/orange shield with exclamation
- **Danger**: Red shield with X or stop sign
- **Disabled**: Gray shield

## Quick Creation Steps

1. **Use Canva or similar tool**
2. **Create 128x128 design first**
3. **Export in smaller sizes**
4. **Test in browser extension**
5. **Adjust for clarity at small sizes**

## Testing Icons

After creating icons:
1. Load extension in Chrome
2. Check toolbar appearance
3. Verify popup icon
4. Test in different themes (light/dark)
5. Ensure visibility at all sizes
